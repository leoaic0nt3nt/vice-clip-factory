# Vice Clip Factory: работа через Codex

Этот репозиторий — продукт для установки, настройки и постоянного выпуска игровых клипов. Пользовательские настройки по умолчанию: ~/.viceclip/config.json. Секреты рядом в secrets/; не читай и не печатай значения в чат/логи, если они не нужны для конкретного подключения.

## Когда покупатель просит установить

1. Проверь ОС, Python и свободный диск. Запусти bash install.sh; он ставит рабочий профиль без клонирования всех дополнительных исходников.
2. Следуй docs/QUICKSTART.md. Для интерактивного подключения предложи пользователю запустить viceclip setup в своём терминале или помоги заполнить профиль через доступные данные без раскрытия секретов.
3. Для настройки кодом: viceclip setup --non-interactive --accept-terms --config PATH --source HTTPS_URL --inbox PATH. Это сохраняет выбранные источники без повторного согласования каждого клипа. Поле source_policy.user_responsible — разовое условие оператора, а не доказательство прав.
4. Google/Meta согласие владельца не обходи. Не извлекай сессии браузера, не используй чужие клиентские приложения из соседних проектов и не встраивай секрет Meta-приложения в продаваемый клиент.
5. Сначала проверь реальный локальный MP4 и целевые аккаунты. Включай публичный выпуск в рамках явного запроса покупателя и настроенного execute, не выдавай preview за опубликованный ролик.

## Управление

- viceclip autopilot tick --preview: один проход без uploads.
- viceclip autopilot start --persistent: фоновая служба с перезапуском ОС.
- viceclip autopilot status / logs / pause / resume / stop.
- Для своего профиля передавай --config PATH каждой команде.
- Новые аккаунты добавляются через viceclip connect; не перезаписывай существующий профиль и пользовательские медиа.

## Реклама и реферальная ссылка

Для покупательского сценария используй `viceclip promo`, а не глобальный legacy style.sponsor_text. Мастер сохраняет кампанию для следующих рендеров: YouTube получает рекламный вариант, Instagram - чистый. Ссылка должна быть размещена владельцем в профиле один раз; обычный URL в описании Shorts некликабелен. Новое промо не перерисовывает готовую очередь. Не обещай автоматическое подключение YPP, реферальных выплат или редактирование профиля.

## Изменения кода

Сначала проверь owning source. Тесты: python -m unittest discover -s tests -v. Используй mock для внешних upload/API. Сохраняй проверки правильного аккаунта, fingerprint, защиту от дублей и неопределённых повторных uploads. Не удаляй обязательные лицензии компонентов. Пользовательская упаковка объясняет наш продукт, внутренние зависимости описаны отдельно.

Никогда не повторяй paid/sent/upload action только ради проверки. После неизвестного исхода сначала выполни сверку существующей сессии/container.
