# Проверка четырёх инструментов для нарезки — 18 ноября 2026

**Решение:** текущий лёгкий конвейер Vice Clip Factory сохраняем. Из четырёх проектов наиболее полезен **Clips Kitty как дополнительный игровой движок в отдельном локальном сервисе**. OpenShorts — второй кандидат для сравнения качества. SupoClip и Cutawan сейчас не добавляем в обязательную установку.

Проверены официальные репозитории и исходники ключевых функций; локальные копии находятся в `tmp/repo-audit/`. Их приложения, установщики и модели в ходе этой проверки **не запускались**. Наличие кода не подтверждает качество отбора моментов на GTA: для такого вывода нужен отдельный тест на одинаковом исходнике.

## Как подключать Clips Kitty при наличии места

Держать движок в отдельном окружении, API — на loopback. Сначала `GET /health/preflight`; затем передать уже скачанный файл через стабильный `POST /videos/local`. Для теста: `max_clips: 2`, `gaming: true`, `gaming_layout: {preset: "blurred", cam: null, safe: "all"}`. Проверять завершение через `GET /jobs/{job_id}`, получать интервалы, оценки и пути через `GET /videos/{video_id}/clips`; готовое видео доступно через `GET /media/{clip_id}`.

Свой автопостинг движка отключить (`auto_upload: false`). Отбор игровых моментов можно сравнить с нашим; рекламу, очередь, выбор аккаунтов и публикацию оставить Vice Clip Factory. До реального рендера и сравнения не выдавать этот вариант за установленный или проверенный. Покупательский PDF этой технической проверкой не меняется.
