# Монтажный свет

Визуальная система наследует ритм пользовательского референса: чёрная и молочная страницы, крупный тонкий grotesk, электрический кобальт, мягкое свечение и тонкие правила. Иллюстрации здесь оригинальные: перспективная последовательность кадров, киноплёнка и схема игровой дороги. Они говорят о монтаже и времени, не подменяя будущий геймплей GTA VI.

Вёрстка строится на 600×800 pt, внешнем поле 36 pt и короткой строке. Верхний колонтитул держит автора и текущий раздел, нижний - название проекта и номер страницы. Крупный заголовок несёт одну мысль; пронумерованные блоки раскрывают действие. Читабельность важнее декоративной плотности.

Шрифт Inter Tight распространяется по SIL Open Font License 1.1. Исходная variable-версия и производные статические начертания находятся в `assets/fonts/`; текст лицензии - `assets/fonts/OFL.txt`. Artwork генерируется детерминированно скриптом `scripts/build_guide.py`. Ни страницы исходного PDF, ни чужие игровые кадры в публичную упаковку не входят.

Палитра: `#080808`, `#F1F1EB`, `#234DFF`, `#A6A6A0`. Поля и тонкие разделители сохраняются даже на визуальных страницах. Макеты вертикального видео подписаны как schematic demo, чтобы не создавать впечатления реального материала GTA VI.

Пересборка: `pip install reportlab pillow numpy`, затем `python scripts/build_guide.py`. Скрипт не требует локальных пользовательских файлов и автоматически проверяет вертикальные границы основных текстовых блоков. Финальная приёмка дополнительно включает рендер всех страниц PDF и визуальную проверку.
