# Работа автопилота

Покупателю достаточно команд из [быстрого старта](QUICKSTART.md). Ниже параметры для настройки через Codex или код.

## Профиль

`viceclip setup` сохраняет `~/.viceclip/config.json`. Собственный профиль передаётся в каждую команду флагом `--config PATH`. Доступы находятся отдельно в secrets/ и не входят в продаваемый пакет.

Один процесс выполняет обнаружение материалов, получение видео, распознавание, анализ, рендер, очередь и публикацию. Источники выбираются при настройке; постоянных подтверждений для каждого клипа нет. `source_policy.mode=configured_sources` - обычный профиль продукта.

## Основные настройки

| Настройка | Значение |
|---|---|
| autopilot.execute | true - реальная загрузка; false - предпросмотр |
| autopilot.privacy | Видимость YouTube: public/private/unlisted |
| autopilot.poll_interval_seconds | Частота прохода, обычно300сек |
| autopilot.accounts | Целевые ID аккаунтов |
| sources[].account_ids | Дополнительная маршрутизация конкретного источника |
| autopilot.posting_gap_seconds | Интервал выпусков одного аккаунта |
| accounts[].max_posts_per_day | Локальный дневной предел |
| autopilot.min_score | Порог отбора кандидатов |
| autopilot.clips_per_source | Максимум клипов из записи |
| autopilot.asr | Включение, модель и язык локальной речи |
| autopilot.live_segments | Ограниченная запись доступных live-фрагментов |
| autopilot.scout_queries | Темы автоматического поиска |
| autopilot.ingest_scout_candidates | Обрабатывать найденное по выбранным темам |
| autopilot.max_pending_jobs | Ограничение запаса очереди |
| autopilot.retention_days | Хранение завершённых рабочих результатов |

Для выбранного автора используйте creators с platform, url, enabled. Для файла — sources с path; для папки — autopilot.inboxes с path и source_id. Подключения и storage задаются мастером.

## Команды

```bash
viceclip autopilot tick --preview
viceclip autopilot run
viceclip autopilot start --persistent
viceclip autopilot status
viceclip autopilot logs
viceclip autopilot pause
viceclip autopilot resume
viceclip autopilot stop
```

Настройки перечитываются в следующем проходе. Остановка завершает текущую обработку; до её окончания статус может показывать stopping. Служба --persistent перезапускается средствами ОС; на Mac после входа пользователя, на Linux через user systemd. Хост должен оставаться включённым.

## Восстановление и ограничения

Локальная база хранит этапы работы и SHA файлов. Завершённые рендеры используются повторно после добавления аккаунта. Скачанные приложением входные файлы удаляются после проверенного рендера; исходники пользователя не удаляются. Старые результаты очищаются только после окончания соответствующих публикаций. Неоднозначные и ожидающие задачи защищены от очистки. Для bucket настройте lifecycle отдельно.

`pending/approved` - подготовка и очередь, `uploading/processing` - загрузка/обработка, `uploaded` - приём YouTube, `published` - ответ Instagram. `playback_verified=false` не объявляет видео просмотренным. `failed` с определённым отказом повторяется с ограничением; `unknown` не повторяется автоматически и требует сверки, чтобы не создать дубликат.

При переполненной очереди автопилот продолжает издатель и приостанавливает новое производство. Квоты аккаунтов и проекта остаются внешними ограничениями. Режим live забирает ограниченные части публичного потока, не гарантируя запись каждого кадра. Источник сверх заданных размера/длительности/времени отклоняется с записью причины.

Основной отбор использует речь, аудио и движение. При отсутствии речи балл нормализуется по доступным сигналам, чтобы молчаливый gameplay мог пройти порог. Это ранжирование кандидатов, не гарантия качества или охвата.

## Промо в новых роликах

`viceclip promo` сохраняет короткий текст, HTTPS-ссылку оператора и позицию плашки. Можно настроить кодом: `viceclip promo --text "Продукт · Ссылка в профиле" --url https://example.test/offer --position bottom`.

В новом рендере сохраняются чистый мастер и отдельная YouTube-версия с рекламным статусом. Очередь выбирает вариант площадки; Instagram не получает рекламный текст или плашку этой кампании. Смена и отключение промо не изменяют уже готовые файлы и очередь. Ссылка размещается в профиле владельцем один раз; программа не превращает текст в кликабельную ссылку и не подключает YPP или выплаты партнёрки.
