# Подключения один раз

Официальные площадки требуют доступа владельца. Приложение сохраняет подключения локально и обновляет поддерживаемые токены автоматически. Обход входа или пароль соцсети для издателя не используется.

## YouTube

Для подключения нужен файл Desktop OAuth client вашего Google-приложения с включённым YouTube Data API v3. Его готовит владелец приложения или специалист запуска. В `viceclip setup` укажите путь к файлу; откроется браузер Google. Выберите нужный канал и разрешите upload/read-only доступ. Название и ID канала проверяются; для следующего канала повторите подключение.

Если вы продавец услуги запуска, подготовьте собственный разрешённый OAuth-маршрут и пройдите необходимую проверку приложения до обслуживания внешних клиентов. Репозиторий не содержит чужого готового client secret. Факт успешного согласия не заменяет проверку кабинета приложения, режима пользователей и квот.

## Instagram

Нужен профессиональный Business/Creator профиль и официальный Instagram Login с правом content publishing. В текущем мастере используется long-lived access token, выпущенный официальным приложением/кабинетом владельца. При коротком токене обмен выполняется владельцем приложения на своей стороне; секрет Meta-приложения не встраивается в продаваемый клиент.

Мастер проверяет профиль и сохраняет токен приватно. Приложение заранее обновляет действующий long-lived токен по поддерживаемому Meta flow. Если разрешение отозвано или токен уже истёк, профиль потребуется подключить снова. Подключение сторонних клиентов может потребовать App Review и проверки бизнеса владельца приложения.

Для доставки роликов создайте S3-совместимый bucket с доступом приложения на чтение/запись. Мастер попросит bucket, endpoint, регион и ключи. Файлы размещаются под неизменяемым именем по содержимому, bucket не становится публичным. Для Meta выдаётся временная HTTPS-ссылка. Адреса каждого MP4 вручную вставлять не нужно. Настройте lifecycle bucket для удаления старых объектов после достаточного срока хранения.

Рекламный partnership flow в текущем издателе Instagram отключён. Обычные редакционные Reels поддерживаются через описанное подключение. Проверяйте применимые ограничения рекламы отдельно.

## Twitch и поиск

Для наблюдения за Twitch нужны Client ID и Client Secret официального приложения. App token система получает и обновляет сама. Для публичных YouTube-каналов можно использовать URL автора; поиск новых авторов по теме дополнительно требует YouTube API key.

## Секреты и перенос

Доступы находятся в `~/.viceclip/secrets/`, права файлов 0600. Ключи не включаются в публичный репозиторий, продаваемый ZIP или лог. Для переноса на сервер настройте профиль там и безопасно передайте свои подключения. При смене владельца аккаунта выполняется новое согласие.
