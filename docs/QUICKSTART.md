# Первый запуск Vice Clip Factory

## Установка

Скачайте пакет продукта, распакуйте его и откройте Терминал в этой папке. На Mac/Linux выполните:

```bash
bash install.sh
```

Установщик проверяет FFmpeg и ставит приложение с необходимыми компонентами. Рекомендуется Python 3.12; модели распознавания скачиваются при первом использовании. Выполните показанную команду `source .../.venv/bin/activate`. Установка дополнительных исходников и GPU для первого запуска не требуется.

## Настройка один раз

```bash
viceclip setup
```

Мастер спросит подпись канала, ссылки на авторов или записи, подключения аккаунтов, частоту выпуска и режим публикации. Подробности доступа — в [инструкции подключения](CONNECT_ACCOUNTS.md). Для Instagram один раз задаётся облачное хранилище; далее доставка файлов автоматическая.

Начните в режиме предпросмотра. Полностью скопированный видеофайл можно положить в папку `~/.viceclip/inbox`. Лучше переносить его после завершения копирования. Это убережёт от обработки незаконченной записи.

## Реклама и ссылка

```bash
viceclip promo
```

Мастер спросит текст плашки, вашу HTTPS-ссылку и положение top/bottom. Например: «Мой продукт · Ссылка в профиле». Саму ссылку один раз добавьте во внешние ссылки профиля канала. В описании Shorts обычный URL не кликабелен.

Новые YouTube-клипы получают рекламный вариант. Instagram получает чистую версию без этой плашки и рекламной подписи. Готовая очередь остаётся прежней. `viceclip promo --show` показывает настройку, `viceclip promo --off` отключает промо для следующих рендеров.

## Проверка и постоянная работа

```bash
viceclip autopilot tick --preview
viceclip autopilot status
viceclip autopilot start --persistent --execute
```

Просмотрите первые ролики из папки output, указанной в конфигурации. Настройка `autopilot.execute` включает реальный выпуск; мастер спрашивает о нём явно. `autopilot.privacy` задаёт видимость YouTube, `accounts[].privacy` позволяет переопределить её для отдельного канала. Для первого закрытого теста поставьте `private`, для публичного выпуска — `public`. Не отправляйте пароли в чат: авторизация проходит через официальный доступ площадки.

`--persistent` создаёт службу пользователя: launchd на Mac и systemd user на Linux. На Mac она запускается после входа пользователя. На Linux работа без сессии может требовать настройки linger администратором сервера. Сон и выключение компьютера останавливают обработку; для настоящей работы 24/7 используйте постоянно работающий сервер.

## Повседневное управление

```bash
viceclip autopilot logs
viceclip autopilot pause
viceclip autopilot resume
viceclip autopilot stop
```

Остановка даёт закончить текущую обработку. При добавлении ещё одного канала используйте `viceclip connect youtube --name channel-2 --client-secrets /path/client.json` или мастер отдельного профиля. Готовые клипы сохраняются, повторно их рендерить для нового аккаунта не требуется.
