# Креатив из ChatGPT Image для всех новых клипов

Сделайте один визуал под оффер. Откройте ChatGPT Image, приложите фото своего товара, если оно есть, и попросите:

> Изолированный квадратный предмет для маленькой рекламной карточки в игровом клипе. Один крупный узнаваемый объект, прозрачный фон, высокие контраст и резкость. Без букв и водяных знаков. Сохранить форму и цвет товара.

Скачайте PNG. В поставке есть готовый пробный рисунок `assets/promo/creator-demo.png`, сделанный ChatGPT Image. Подойдут также статичные JPEG и WebP до 12 МБ и 16 Мп. Vice Clip Factory ставит текст и анимирует появление и уход карточки над продолжающимся видео. Для каждого ролика используется сохранённый файл, повторная генерация не нужна.

```bash
viceclip promo --text 'Creator Toolkit' --url 'https://example.com/offer' \
  --artwork ./promo.png --position top --start 4 --seconds 4 \
  --language en --cta 'Get the kit · Link in profile'
viceclip revenue link
viceclip autopilot tick --preview
```

Замените текст, URL и имя файла своими. `top` и `bottom` задают место. `--start` задаёт секунду появления, `--seconds` — длительность в диапазоне 1–8 секунд. Для слишком короткого клипа программа сдвинет показ в доступный интервал. В верхней позиции при пересечении с хуком карточка располагается ниже него. Звук игры продолжается.

Скопируйте URL с UTM из `revenue link` в профиль YouTube. Стандартный CTA можно заменить короткой фразой с `--cta`. Для русской серии укажите `--language ru`.

```bash
viceclip promo --position bottom --start 6 --seconds 3
viceclip promo --artwork ./new-offer.png
viceclip promo --show
viceclip promo --off
```

Каждая новая нарезка использует сохранённую кампанию. Для YouTube создаётся версия с промо и отметкой платной интеграции. В Instagram уходит чистая версия. Если обновился оффер, укажите новый URL и его изображение. Используйте `--no-artwork`, чтобы оставить карточку с текстом. Проверьте кадр с рекламой и путь по ссылке в первом выпуске.

Для коммерческой интеграции используйте согласованный формат, покажите раскрытие рядом с оффером и сохраните геймплей в кадре. [Политика YouTube о платном продвижении](https://support.google.com/youtube/answer/154235) · [Измерение переходов](REVENUE.md)
