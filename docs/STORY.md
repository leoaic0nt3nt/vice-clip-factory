# Сюжетный отбор и вебка стримера

Включите отбор по сюжету в существующем профиле. В новом профиле он включён по умолчанию.

```bash
viceclip story --on
viceclip story --show
```

Редактор ищет законченную игровую сцену. В первые пять секунд зритель получает завязку. Дальше видно попытку, трюк, подкол или ход миссии, а в конце — результат и реакцию. Заголовок задаёт вопрос или показывает ставки. Рендер сохраняет сцену целиком, включая тихие секунды внутри действия. Если кадров для подтверждения развязки мало, источник может дать ноль клипов. В длинной трансляции редактор проверяет выбранные по движению и звуку участки записи.

## Добавить вебку

Для вертикальных шортов укажите область камеры на исходном кадре. Пример ниже подходит для записи xQc из теста GTA V.

```bash
viceclip facecam --source source-1 --rect 0 .297 .192 .278 --position left
viceclip facecam --source source-1 --show
viceclip autopilot tick --preview
```

`source-1` — пример ID из `sources` или `creators` в профиле. Для входной папки по умолчанию используйте `inbox`. Четыре значения `--rect` задают отступы слева и сверху, ширину и высоту в долях исходного кадра. Разметьте область один раз для каждого канала, пока он использует тот же макет. `--position right` перенесёт окно вправо. В вертикальном клипе окно берётся из того же кадра, что и игра. Если камера уже видна в основном кропе и кадр нельзя сдвинуть без потери действия, программа сохраняет её там.

Проверьте первый результат в папке `output`. `viceclip facecam --source source-1 --off` убирает отдельное окно. `viceclip story --off` возвращает обычный отбор. Изменения применяются к новым планам.

## Проверка на GTA V

Два отрывка из одной трансляции xQc прошли предпросмотр с GPT-6.2 Sol. У прыжка редактор сохранил разгон, полёт под парашютом и посадку на соседней крыше. У падения с лестницы оставил подход к краю, падение и реакцию стримера с английскими субтитрами. Для каждого эпизода сформированы чистый мастер и английский рекламный вариант.
