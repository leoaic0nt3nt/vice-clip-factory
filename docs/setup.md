# Установка Vice Clip Factory

Для покупателя: [быстрый старт](QUICKSTART.md) и [подключение каналов](CONNECT_ACCOUNTS.md).

```bash
bash install.sh
# Активируйте окружение командой из вывода установщика.
viceclip setup
viceclip autopilot start --persistent
```

Обычный установщик ставит рабочий профиль autopilot: приложение, downloader, локальное распознавание, OAuth и облачную доставку. Он не требует клонирования больших дополнительных репозиториев. При первом ASR скачивается модель; `bash install.sh --download-model` подготавливает базовую модель заранее.

Рекомендуются Python3.12, macOS14+ или Linux с поддерживаемыми wheel-пакетами, FFmpeg, свободное место и постоянный интернет. GPU не нужен для первого запуска. Точная скорость зависит от записи и оборудования.

## Для разработчика

`python scripts/bootstrap.py` остаётся расширенным маршрутом работы с закреплёнными исходниками. `--profile medusa` подключает отдельный необязательный игровой движок; его условия и ключи описаны в технической документации. Старые команды локального ядра продолжают работать.

[Руководство прежнего профиля0.1](legacy-setup-v0.1.md) сохранено для совместимости. Для нового покупательского запуска используйте мастер и единый автопилот.
