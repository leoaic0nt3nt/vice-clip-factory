## Проверка 0.5

- GPT-6.2 Sol на восьмиминутной записи GTA V выбрал два сценных отрезка и написал английские заголовки. Кадры и русская речь взяты из исходника. Локальная ASR остаётся на языке записи.
- Реальная очередь в режиме preview собрала два ролика по 24,63 и 20,53 секунды, по одному чистому и рекламному файлу на каждый. Кадр 1080×1920, Roboto Condensed Black и карточка со сгенерированной ChatGPT Image графикой. Показ с четвёртой до восьмой секунды. Все четыре MP4 декодированы; звук рекламных и чистых версий совпал по хешу декодированной дорожки.
- Повторный preview сохранил четыре файла и четыре идентификатора задач для тестовых YouTube и Instagram профилей. Проверка возобновления YouTube, видимости, статуса обработки и отметки платной интеграции выполнена на имитации ответов API и реальной SQLite-очереди. Боевой загрузки и публичного воспроизведения в этой проверке не было.
- Покупательский PDF проверен на всех восьми страницах. Включены [настройка креатива](PROMO.md), [YouTube от подключения до проверки ролика](YOUTUBE.md) и [план монетизации на 14 дней](MONETIZATION.md).

## Новое в 0.4

Полный свежий проход на 480-секундной записи GTA V: локальное распознавание small → реальный запрос GPT-6.2 Sol → две отдельные законченные сцены → четыре MP4 → восемь одобренных задач для двух YouTube и двух Instagram профилей. Никаких ручных заголовков, границ сцен или занижения обычного порога в этом проходе не использовано. Видео: 24.867 и 20.333 секунды, 1080×1920, 30 fps, H.264/yuv420p и AAC 48 kHz. Все четыре файла полностью декодированы без ошибок.

Картинка заполняет вертикальный кадр, в первом клипе активное слово выделяется цветом, во втором используются короткие фразы. YouTube получает компактное промо продукта/CTA, Instagram — чистый мастер. Повторный проход за 0.75 секунды не изменил MP4 и ID восьми задач.

Установщик реально установил профиль 0.4.0 с EJS/Deno, локальным ASR и Codex CLI. Вход Codex проверен в установленной копии. Реальная launchd-служба на отдельном preview-профиле обработала короткий локальный файл, была видна running и затем остановлена; тестовый LaunchAgent удалён остановкой.

Реальный журнал выпуска показывает два готовых клипа, восемь ожидающих задач и ноль опубликованных роликов/выплат. UTM-ссылки, идемпотентный CSV-импорт, возвраты, разные валюты и защита от привязки старого клипа к новому офферу проверены тестами. Показатели просмотров и дохода не генерируются из оценок модели.

Проверены восстановление после отсутствующего входа Codex без расходования попыток источника, сохранение Node/Codex PATH для службы, неполные word timestamps WhisperX и старые пути баз без явных настроек.

## Исправления первого GTA V теста, включённые в 0.4

Первый реальный GTA V прогон выявил два дефекта: заголовок мог обрезаться внутри слова, а субтитр показывал весь ASR-сегмент, включая речь вне выбранного клипа. Теперь хук сокращается по словам до70 символов; word timestamps отбирают только речь внутри сохранённых интервалов и формируют короткие реплики. Транскрипты без word timestamps сохраняют прежний режим.

Рендер делает точный seek в выбранный фрагмент вместо полного декодирования длинного входа для каждого клипа. Реальный FFmpeg-тест проверяет две поздние части исходника после склейки: картинка совпадает с правильными исходными моментами, звук присутствует, длительность2 секунды. Тесты не ограничиваются проверкой аргументов процесса.

Подробности GTA V прогона: [real-gameplay-test.md](real-gameplay-test.md). Проверка четырёх новых проектов: [toolkit-audit-2026-11-18.md](toolkit-audit-2026-11-18.md).

## Новое в0.3

Реальный `viceclip promo` сохранил кампанию с текстом и ссылкой, после чего единый автопилот из6-секундного синтетического входа создал два отдельных MP4 и две задачи в preview-очереди. YouTube-вариант содержит плашку «Реклама: Мой продукт · Ссылка в профиле», sponsored=true и рекламную подпись; Instagram-мастер и его caption чистые. Оба MP4 декодируются без ошибок. Дополнительно проверена верхняя плашка на широком игровом формате: она остаётся выше изображения. Подписанная ссылка/облако и реальные upload API не вызывались.

Агент «адвокат дьявола» проверил новый8-страничный текст: удалены выдуманные суммы, агентская модель и абстрактные заголовки. Оставлены действия пользователя и ссылки на официальную справку YouTube. Доход и monetization не выдаются за автоматически подключённые программой.

## Что проверено тестами

- Выбор источников задаётся один раз, без требования документов к каждому клипу.
- Новый аккаунт получает готовые клипы из preview, без нового рендера.
- Ошибка одного источника или аккаунта не останавливает остальные.
- Неопределённая загрузка не повторяется вслепую.
- Instagram обрабатывает тот же сохранённый container и получает файл через автоматическую облачную доставку.
- Токены поддерживаемых Google/Meta/Twitch подключений обновляются по официальным потокам.
- Ограничены запас очереди, повторы и объём обработки; скачанные приложением входы удаляются, пользовательские оригиналы сохраняются.
- Тихий/безречевой gameplay не блокируется только отсутствием ASR-маркеров.
- Команда stop работает даже при повреждённой конфигурации.

## Граница подтверждённого

Боевые Google/Meta/Twitch приложения и аккаунты покупателя не подключались. Реальные YouTube/Instagram публикации и облачная передача в аккаунт владельца не выполнялись. До первого коммерческого запуска требуется проверочная публикация после официального подключения. Тесты не подтверждают охват, заработок или решение площадки о монетизации.

Linux systemd service проверяется по структуре, реальная OS-служба проверена на macOS. Непрерывный многосуточный прогон, нагрузка большого флота и near-live latency не измерены. Синтетическое техническое демо оставлено для повторяемой проверки. Отдельно проведены реальные GTA V тесты; GTA VI gameplay здесь не использовался. Кроп фиксирован на клип, не является покадровым трекингом. ASR может ошибаться, а AI оценивает выбранные кадры и речь, не каждый кадр многочасового источника.

## Повторение

```bash
python -m unittest discover -s tests -v
python -m compileall -q src scripts
bash -n install.sh
viceclip autopilot tick --preview
viceclip autopilot status
```

GitHub Actions проверяет установку основного пакета, тесты и compileall. Тяжёлый игровой Medusa-профиль остаётся опциональным; основной покупательский профиль реально установлен и проверен локально.
