# Автопостинг YouTube Shorts

## Подключение своего канала

1. В своём проекте Google Cloud включите YouTube Data API v3. Настройте экран согласия и создайте Desktop OAuth client. Скачайте JSON этого клиента.
2. Подключите канал. В открывшемся окне Google выберите нужный YouTube-канал и разрешите чтение и загрузку.
3. Сверьте имя и ID канала. Система сохраняет обновляемый токен в приватный файл и проверяет ID канала перед каждой загрузкой.

```bash
viceclip connect youtube --name gta-main --client-secrets /path/to/client.json
viceclip youtube check --account gta-main
```

Проверка читает данные канала через API. Она может обновить локальные данные входа. Для каждого дополнительного канала выберите его в отдельном подключении с уникальным `--name`. Используйте собственное приложение и храните JSON и токены вне репозитория.

У внешнего OAuth-приложения в режиме **Testing** refresh token для этих разрешений обычно истекает через семь дней. Для постоянной работы настройте аудиторию и режим приложения в Google Auth Platform. Следуйте требованиям Google к проверке приложения, если распространяете его сторонним пользователям. [Жизненный цикл OAuth-токенов](https://developers.google.com/identity/protocols/oauth2#expiration).

2 ноября 2026 года YouTube отменил прежнее ограничение, которое автоматически переводило загрузки из непроверенных API-проектов в private. Для увеличения квоты может потребоваться аудит. Программа задаёт видимость явно, а её текущее значение после загрузки можно сверить через API. [История изменений](https://developers.google.com/youtube/data/revision_history) · [Квоты и аудит](https://developers.google.com/youtube/data/guides/quota_and_compliance_audits).

## Первый выпуск

Сначала выполните `viceclip autopilot tick --preview` и посмотрите видео из папки output профиля. Проверьте текст, сцены, голос, плашку и правильный канал. Preview формирует очередь локально.

Для первой реальной загрузки используйте отдельную базу очереди и один готовый файл из настроенного источника. Берите `source_id` из JSON рядом с MP4. Одобрите только ID, который вернёт команда `add`.

```bash
viceclip queue add /path/to/clip.mp4 --config ~/.viceclip/config.json \
  --db ~/viceclip-first-upload.sqlite3 --source-id source-1 --account gta-main \
  --title "First clip" --privacy private
viceclip queue approve 1 --db ~/viceclip-first-upload.sqlite3
viceclip queue run --execute --config ~/.viceclip/config.json --db ~/viceclip-first-upload.sqlite3
```

В примере замените `1` на полученный ID. Для платной интеграции укажите `--sponsored`: при наличии JSON рядом с видео программа сама подхватит этот признак из проверенных параметров рендера. Отправка возвращает ID видео. Подставьте его в следующую проверку.

```bash
viceclip youtube check --account gta-main --video-id VIDEO_ID --privacy private
```

Смотрите `upload_status`, `processing_status` и `privacy_matches`. При успешной обработке откройте видео в Studio и проверьте воспроизведение целиком. Для первого публичного ролика дополнительно откройте обычную ссылку из браузера без входа. `uploaded` означает, что API принял видео и вернул ID. Отчёт `youtube check` показывает информацию YouTube о статусе и видимости. Проверка фактического воспроизведения выполняется в браузере. [Метаданные видео](https://developers.google.com/youtube/data/reference/rest/v3/videos/list).

## Постоянная работа и восстановление

- `viceclip autopilot start --persistent --execute` запускает службу. Она отправляет одобренные клипы, когда наступает локальное расписание. Видимость задаёт `autopilot.privacy`, а `accounts[].privacy` переопределяет её для отдельного канала. Выберите `public` перед созданием публичных заданий. Видимость фиксируется при постановке в очередь. При `private` видео остаётся в закрытом режиме до решения владельца.
- Интервал задаёт `autopilot.posting_gap_seconds`, лимит за 24 часа — `accounts[].max_posts_per_day`. При известном отказе по квоте задача ждёт. Проектные квоты по документации на 18 ноября 2026 — 100 вызовов `videos.insert` и 100 вызовов `search.list` в сутки в отдельных корзинах, плюс 10 000 единиц для остальных методов. Сброс в полночь по Pacific Time. Сверьте фактическую квоту проекта в Google Cloud и отдельные лимиты канала. [Таблица квот](https://developers.google.com/youtube/data/determine_quota_cost).
- При обрыве передачи или перезапуске программы очередь продолжает сохранённую сессию с последнего подтверждённого байта. Если YouTube уже подтвердил загрузку, программа забирает существующий ID. Если сессия пропала или результат не подтверждён, статус `unknown` останавливает повтор. Найдите ролик в Studio, подтвердите нужный ID через `youtube check`, затем используйте `viceclip queue reconcile ID --remote-id VIDEO_ID --db PATH`. Для `PATH` возьмите путь к очереди профиля из `autopilot.publish_db`. [Протокол возобновляемой загрузки](https://developers.google.com/youtube/data/guides/using_resumable_upload_protocol).
- `viceclip autopilot status`, `viceclip autopilot logs` и `viceclip revenue report` показывают состояние выпуска. При отказе Google в доступе проверьте настройки OAuth, согласие и выбранный канал. Если подключение отозвано, получите новое согласие владельца.

## Что влияет на монетизацию Shorts

- YouTube относит к Shorts квадратные или вертикальные видео длиной до трёх минут для обычных каналов. Шаблон 9:16 выпускать проще. У Shorts длиннее минуты активный Content ID claim блокирует показ во всём мире. Отключите игровое радио до записи или очистите музыку с подходящими правами. [Условия Shorts до трёх минут](https://support.google.com/youtube/answer/15424877).
- При платном размещении API передаёт отметку YouTube о коммерческой интеграции. Компактная плашка сопровождает продолжающийся сюжет. Отдельные видеоролики рекламодателя в середине, начале или конце YouTube ограничивает. Для отдельной вступительной спонсорской карточки площадка допускает статичное изображение до 5 секунд и требует совместный брендинг, если карточка появляется в самом начале. [Правила платных интеграций](https://support.google.com/youtube/answer/154235).
- Ссылка из `viceclip revenue link` размещается в профиле канала. Обычные URL в описании и комментариях Shorts некликабельны. Коммерческие ссылки и сами офферы должны соответствовать правилам площадки. [Где работают ссылки](https://support.google.com/youtube/answer/13748639) · [Правила внешних ссылок](https://support.google.com/youtube/answer/9054257).
- Оригинальные сюжеты, собственный геймплей, комментарий или разбор дают каналу больше оснований пройти проверку YPP. Простой кроп чужого клипа, текст и реклама могут не пройти проверку reused content даже с разрешения автора. Подтвердите коммерческие права на запись, игру и звук. Общая политика Rockstar для фанатских публикаций описывает некоммерческое использование. [Монетизация канала](https://support.google.com/youtube/answer/1311392) · [Игровой контент](https://support.google.com/youtube/answer/138161) · [Политика Rockstar](https://support.rockstargames.com/articles/7bNaeoMFTV0iUDGhStTXvz/policy-on-posting-copyrighted-rockstar-games-material).
- Отдельно проверяйте доход с рекламы Shorts в YouTube Studio, заказы в магазине и выплаченные комиссии в партнёрской программе. Доступ к YPP зависит от условий канала и страны. В текущих правилах Google реклама для зрителей в России приостановлена, как и новые регистрации YPP в России и монетизация через российские аккаунты AdSense для YouTube. Англоязычный выпуск меняет язык материалов и аудиторию. Условия выплат проверяйте по своему реальному аккаунту. [Допуск в YPP](https://support.google.com/youtube/answer/72851) · [Региональные ограничения](https://support.google.com/youtube/answer/1311392).
