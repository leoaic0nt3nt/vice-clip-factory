# Партнёрские комиссии с клипов

## 1. Добавьте оффер и ссылку

```bash
viceclip promo --text 'Промокод LEO · Ссылка в профиле' --url 'https://partner.example/product?ref=LEO' --position bottom
viceclip revenue link
```

Скопируйте `url` из результата в раздел внешних ссылок своего канала YouTube. Программа сохраняет партнёрские параметры и добавляет UTM-метки. `campaign_id` привязан к исходному адресу оффера. Для общей ссылки в профиле Instagram используйте `viceclip revenue link --platform instagram`. Флаг `--platform` задаёт только источник перехода в ссылке, а Instagram получает чистую версию клипа. Обычный URL в описании и комментариях Shorts некликабелен. [Где YouTube поддерживает ссылки](https://support.google.com/youtube/answer/13748639).

Общая ссылка в профиле позволяет учесть кампанию целиком. Для привязки к ролику YouTube возьмите его `clip_id` из `viceclip revenue report` и выполните `viceclip revenue link --clip-id SHA256`. Команда проверяет, что ролик сохранён с активным оффером. Используйте уникальный адрес в кликабельном размещении, которое относится к этому ролику, либо сопоставьте отдельный промокод или выбор ролика на лендинге с его `clip_id`. Партнёр или ваш лендинг должен сохранять метку до конверсии. При общей ссылке оставляйте `clip_id` в CSV пустым.

Перед размещением откройте итоговый адрес и проверьте, что партнёрская программа принимает его параметры. Для подписанной ссылки используйте исходный адрес и идентификатор кампании в выгрузке провайдера.

## 2. Импортируйте подтверждённые данные партнёра

Приведите выгрузку партнёра к CSV в UTF-8. Ниже пример структуры с ожидающей конверсией.

```csv
event_id,campaign_id,clip_id,status,amount,currency,updated_at
network:123,offer-0123456789ab,,pending,0,USD,2026-11-18T12:00:00+03:00
```

- `event_id` объединяет код партнёра и постоянный идентификатор конверсии через двоеточие. Повторная выгрузка с тем же ID и временем загрузится без дублей.
- `amount` — сумма вашей комиссии в `currency`, с точкой и максимум шестью знаками после неё. Используйте `paid` для фактически выплаченной комиссии, `pending` для ожидающей, `rejected` для отклонённой.
- При полном возврате передайте тот же `event_id`, статус `refunded` и более позднее `updated_at`. При частичном возврате обновите выплаченную сумму комиссии с тем же ID и статусом `paid`.
- `updated_at` — время изменения записи у партнёра с часовым поясом. Журнал оставляет запись с самым поздним временем.

```bash
viceclip revenue import partner-export.csv
viceclip revenue report
```

Для отдельного профиля укажите `--config /путь/к/config.json` после подкоманды.

## 3. Сверьте выпуск и комиссии

Отчёт показывает число готовых клипов из истории автопилота и статусы очереди по аккаунтам. `uploaded` означает, что YouTube принял загрузку. `published` и `playback_verified` отражают отдельные статусы, записанные в очереди. Комиссии складываются по валютам, кампании и ролику при наличии `clip_id`. Пустой журнал до импорта показывает `available: false`.

Смотрите охват в аналитике самих платформ и сверяйте перечисления с кабинетом партнёра. Монетизацию YouTube владелец канала подключает через YouTube Studio при выполнении условий YPP. Vice Clip Factory ведёт локальный журнал партнёрских комиссий по предоставленным выгрузкам. [Условия YouTube Partner Program](https://support.google.com/youtube/answer/72851).
