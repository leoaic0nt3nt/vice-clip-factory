## Что проверено тестами

- Выбор источников задаётся один раз, без требования документов к каждому клипу.
- Новый аккаунт получает готовые клипы из preview, без нового рендера.
- Ошибка одного источника или аккаунта не останавливает остальные.
- Неопределённая загрузка не повторяется вслепую.
- Instagram обрабатывает тот же сохранённый container и получает файл через автоматическую облачную доставку.
- Токены поддерживаемых Google/Meta/Twitch подключений обновляются по официальным потокам.
- Ограничены запас очереди, повторы и объём обработки; скачанные приложением входы удаляются, пользовательские оригиналы сохраняются.
- Тихий/безречевой gameplay не блокируется только отсутствием ASR-маркеров.
- Команда stop работает даже при повреждённой конфигурации.

## Граница подтверждённого

Боевые Google/Meta/Twitch приложения и аккаунты покупателя не подключались. Реальные YouTube/Instagram публикации и облачная передача в аккаунт владельца не выполнялись. До первого коммерческого запуска требуется проверочная публикация после официального подключения. Тесты не подтверждают охват, заработок или решение площадки о монетизации.

Linux systemd service проверяется по структуре, реальная OS-служба проверена на macOS. Непрерывный многосуточный прогон, нагрузка большого флота и near-live latency не измерены. Медиа-демо синтетическое и не является GTA VI gameplay; его captions написаны для проверки монтажа, в звуке тестовый тон.

## Повторение

```bash
python -m unittest discover -s tests -v
python -m compileall -q src scripts
bash -n install.sh
viceclip autopilot tick --preview
viceclip autopilot status
```

GitHub Actions проверяет установку основного пакета, тесты и compileall. Тяжёлый игровой Medusa-профиль остаётся опциональным; основной покупательский профиль реально установлен и проверен локально.
